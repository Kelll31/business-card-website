Offload

Локальная модель-помощник для Claude Code, Cursor, VS Code, Codex и других IDE. Windows-приложение в трее само ставит llama.cpp, скачивает модель для программирования, настраивает агент OpenCode и подключается к IDE как MCP-сервер, чтобы рутинная работа уходила на бесплатную локальную модель. Один exe, без Docker и прав администратора.
